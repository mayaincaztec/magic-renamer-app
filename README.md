# Magic Renamer PRO

Ứng dụng desktop tự động đổi tên (và hệ thống hóa) văn bản pháp lý tiếng Việt bằng AI.

## Sử dụng (bản Portable — không cần cài đặt)

1. Tải **`MagicRenamerPro-1.0.49-portable.exe`** và **`Thu vien viet tat.json`**.
2. Đặt **cả hai file trong cùng một thư mục**.
3. Chạy `MagicRenamerPro-1.0.49-portable.exe`.
4. Lần đầu mở, vào **Cấu hình** nhập nguồn AI (Google Gemini hoặc Custom OpenAI-compatible: Base URL / Model / API Key).

## Từ điển viết tắt

`Thu vien viet tat.json` chứa danh sách *cụm từ → viết tắt* dùng khi đặt tên file. Mở bằng Notepad để thêm/sửa; ứng dụng đọc trực tiếp file này **đặt cạnh .exe**, không cần build lại.

## Yêu cầu

- Windows 10/11 (64-bit).
- Kết nối Internet + API Key AI hợp lệ.
